# Changelog

## 2025-12-20 — نسخه ۱.۰.۰ 🎉

### 🚀 انتشار ۱.۰.۰ — اولین نسخه پایدار

این نسخه اولین انتشار پایدار نِسار است که شامل قابلیت‌های کامل مدیریت آزمون، تقویم جلسات، جستجوی مراقبین و بهبودهای متعدد UI/UX می‌باشد.

#### ✨ قابلیت‌های جدید (Features)

- **تقویم جلسات آزمون:** نمای هفتگی کامل با رنگ‌بندی بر اساس ساعت جلسه
- **جستجوی Spotlight مراقبین:** جستجوی سریع با کیبورد و موس به سبک macOS Spotlight
- **گزارش جلسات مراقب:** جدول کامل با ستون‌های ردیف، تاریخ، ساعت و وضعیت
- **نمایش سریع جزئیات جلسه:** گزینه جدید در تنظیمات برای رفتن مستقیم به گزارش بدون مودال واسط
- **کارت مراقبین:** جایگزین کارت جلسات باقیمانده با قابلیت جستجو

#### 🛠️ بهبودها (Improvements)

- **بهبود تقویم:** نمایش تاریخ برای روزهای خالی، هاور ظریف با opacity
- **بهبود مودال جستجو:** پس‌زمینه گلس‌مورفیسم، مخفی کردن اسکرول‌بار، رنگ متن مناسب
- **بهبود جدول جلسات:** رنگ‌بندی ردیف‌های یک در میان و هاور
- **یکسان‌سازی ساختار گزارشات:** جدول‌بندی مشابه سایر گزارش‌ها

#### 🔧 رفع اشکالات (Fixes)

- **رفع مشکل API جستجوی مراقب:** حذف ستون‌های ناموجود از کوئری
- **رفع محاسبه آمار:** شمارش صندلی‌ها به جای دانشجویان یکتا برای مجموع صحیح

#### 🗑️ حذف‌ها (Removed)

- **حذف گزینه ارسال پیامک:** از مودال تنظیمات حذف شد
- **علامت‌گذاری کدهای مرده:** توابع SMS و جلسات باقیمانده برای حذف علامت‌گذاری شدند
