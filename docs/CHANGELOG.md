## 2025-10-22 — نسخه ۱.۷.۶

### ✨ قابلیت‌های جدید

- **پیاده‌سازی سیستم Cache و Grace Period برای لایسنس**
  - Grace Period 24 ساعته: در صورت عدم دسترسی به سرور لایسنس، تا 24 ساعت سیستم کار می‌کند
  - استفاده از cache تاریخ انقضا: اگر سرور در دسترس نباشد، از آخرین تاریخ انقضا استفاده می‌شود
  - Fallback هوشمند: در صورت نبود cache، اجازه دسترسی موقت داده می‌شود

### 🔧 بهبودها

- **مدیریت خطای سرور لایسنس:**
  - ذخیره آخرین وضعیت موفق بررسی (`LicenseLastSuccessCheck`)
  - ذخیره وضعیت هر بررسی (`LicenseLastStatus`: valid/invalid/error)
  - لاگ‌گذاری کامل تمام حالات با emoji برای debugging راحت‌تر
  
- **API های جدید:**
  - `API/updateLicenseStatus.php`: ذخیره وضعیت و تاریخ آخرین بررسی موفق
  - `API/getLicenseCache.php`: دریافت اطلاعات cache شده لایسنس

- **بهبود تجربه کاربری:**
  - پیام‌های شفاف‌تر در مورد وضعیت لایسنس
  - نمایش زمان باقیمانده Grace Period در console
  - کاهش قطعی سرویس به دلیل مشکلات شبکه

### 📚 مستندات

- اضافه شدن `docs/LICENSE_CACHE_GRACE_PERIOD.md` با توضیحات کامل:
  - فلوچارت تصمیم‌گیری سیستم
  - جدول سناریوهای مختلف
  - API Reference کامل
  - راهنمای debugging

### 🔒 امنیت

- تمام منطق در JavaScript obfuscated شده پنهان می‌ماند
- Grace Period محدود به 24 ساعت است
- لایسنس منقضی شده قابل استفاده نیست
- تمام رویدادها لاگ می‌شوند
